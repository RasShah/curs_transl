# Справка пользователя TableScript 1.0.0

## Назначение и запуск

TableScript создаёт Python-программы для расчёта небольших электронных таблиц. Вы описываете значения и формулы в текстовом файле, переводите его в `.py`, затем запускаете полученную программу. Результат — CSV, открываемый табличными редакторами. Графический интерфейс не требуется.

В Windows готовый комплект запускается без установки Python. Распакуйте архив полностью и откройте терминал в папке проекта:

```powershell
.\bin\translator.exe input.tbl -o output.py
.\bin\translator.exe --python output.py
```

При использовании исходников или переносимого `translator.pyz` нужен Python 3.10+:

```text
python translator.py input.tbl -o output.py
python output.py
python bin/translator.pyz input.tbl -o output.py
```

После установки проекта через `python -m pip install .` доступна команда `translator input.tbl -o output.py`. Ключ `-o` обязателен. `--show-order` показывает порядок вычисления, `--help` выводит справку, `--version` — версию. Пути с пробелами заключайте в кавычки. Файловое расширение `.tbl` рекомендуется, но не проверяется.

## Файл программы

Кодировка — UTF-8; в начале допускается BOM. Окончания строк LF, CRLF и CR допустимы. Каждая команда заканчивается `;`. Пробелы и переводы строк между токенами несущественны. Табуляция считается одним символом позиции. Адреса, ключевые слова и имена функций не зависят от регистра; содержимое строк зависит.

В программе нужна хотя бы одна ячейка и ровно одна команда `export`. Ячейка определяется только один раз. Порядок команд произволен; `export` описывает результат всей таблицы, даже если стоит в начале файла.

```text
export "result.csv";
B1 = A1 * 2;
A1 = 10;
```

`B1` получит 20. Повторное `A1 = 30;` вызовет ошибку повторного определения. Это декларативная таблица: команды не являются последовательностью присваиваний переменным.

## Ячейки и значения

Адрес состоит из латинских букв столбца и номера строки от 1: `A1`, `B12`, `AA10`. `A0`, `A01`, `1A` недопустимы. Столбцы ограничены A…FAN (4096), строки — 1…100000. В левой части определения `$` не допускается; в формуле он закрепляет соответствующую координату при `fill`.

Числа: `12`, `-4`, `2.5`, `.5`, `2.`, `1.2e-3`. Знак — отдельная операция. Десятичный разделитель — точка; шестнадцатеричные числа, `NaN`, бесконечность не поддерживаются. Целые хранятся как Python `int`, дробные — как двоичные `float` двойной точности. Деление `/` и `AVG` возвращают дробное число. Результат целочисленной операции ограничен 4096 битами. Переполнение дробных операций является ошибкой; при уменьшении результата возможно округление до нуля. Ненулевой литерал, который сразу округляется в ноль, отклоняется при чтении.

Строки заключаются в одинарные или двойные кавычки: `"текст"`, `'да'`. Внутри допускаются `\\`, `\"`, `\'`, `\n`, `\r`, `\t`. Неизвестные escape-последовательности и физический перевод строки до закрывающей кавычки запрещены. Для Windows-пути используйте `"data/result.csv"` или `"data\\result.csv"`.

Логические значения — `true` и `false`. Число 0 не заменяет `false`, а 1 не заменяет `true`.

## Операции

Приоритет от высокого к низкому: скобки и вызовы; унарные `+` и `-`; `* / %`; `+ -`; сравнения `== != < <= > >=`. Бинарные арифметические операции одного приоритета выполняются слева направо. `%` — остаток с правилами Python, знак ненулевого остатка совпадает со знаком делителя. Возведение в степень не предусмотрено.

- Арифметика и унарные знаки требуют числа; логические значения числами не считаются.
- `+` также соединяет две строки. Автоматического преобразования числа в строку нет.
- `==` и `!=` сравнивают значения одного типа, включая логические.
- `< <= > >=` сравнивают два числа либо две строки. Строки сравниваются по порядку символов Unicode.
- Цепочки наподобие `1 < A1 < 10`, логические операторы и пользовательские функции отсутствуют. Для условий можно вкладывать `IF`.

```text
A1 = 2 + 3 * 4;             # 14
B1 = (2 + 3) * 4;           # 20
C1 = "готов" + "о";
D1 = A1 <= B1;              # true
E1 = IF(D1, "да", "нет");
```

## Диапазоны и функции

`A1:B3` — прямоугольник с включёнными границами. Начало должно быть левее и выше конца. Ячейки перечисляются по строкам. Каждая ячейка прямоугольника должна быть определена: пустые промежутки автоматически в ноль не превращаются. Диапазон нельзя присвоить ячейке, использовать в арифметике или вернуть из `IF`.

| Функция | Аргументы | Результат |
|---|---|---|
| `SUM` | Один или больше числовых выражений и/или диапазонов | Сумма всех чисел |
| `AVG` | Как у `SUM` | Сумма, делённая на количество чисел |
| `MIN` | Как у `SUM` | Наименьшее число |
| `MAX` | Как у `SUM` | Наибольшее число |
| `IF` | Ровно три: логическое условие и два выражения одинакового скалярного типа | Выбранное выражение |

Например: `SUM(A1:A3, 10, B1*2)`. Пересекающиеся диапазоны и повторённые аргументы учитываются повторно. Строки и `true`/`false` внутри агрегируемого диапазона запрещены.

`IF(true, 1, 1/0)` возвращает 1: невыбранное выражение не вычисляется. При трансляции проверяются обе ветви: `IF(true, 1, Z9)` ошибочно, если Z9 не определена; `IF(true, 1, A1)` внутри A1 создаёт цикл. Все определённые ячейки таблицы вычисляются, даже если другая формула в итоге не использовала ссылку на них.

## Копирование формул

```text
A1=120; B1=3;
A2=80; B2=2;
fill C1:C2 = A1 * B1;
```

Формула записана для верхней левой ячейки цели. Для C1 она остаётся `A1*B1`, для C2 становится `A2*B2`. Команда определяет все ячейки цели, включая первую. Предварительно определять C1 нельзя. Цель может быть двумерной: `fill C1:D3 = ...;`.

При смещении на один столбец вправо и одну строку вниз:

| Ссылка | После копирования |
|---|---|
| `A1` | `B2` |
| `$A$1` | `$A$1` |
| `$A1` | `$A2` |
| `A$1` | `B$1` |
| `A1:A2` | `B2:B3` |

Оба конца диапазона смещаются по собственным флагам `$`. Строки и числовые константы не меняются. Ссылки внутри вложенных функций также копируются. Перекрытие двух команд `fill` либо `fill` и обычного определения — ошибка. Выход ссылки за границы и перевёрнутый после копирования диапазон — ошибки.

## Экспорт и комментарии

`export "result.csv";` задаёт имя результата. Если путь относительный, он отсчитывается от каталога создаваемой `.py`-программы. Абсолютный путь используется как указан. Каталог должен существовать. Содержимое CSV кодируется UTF-8 без BOM; разделитель — запятая, строки заканчиваются LF, встроенные кавычки и переводы строк экранируются стандартным модулем `csv`.

Экспортируется прямоугольник от A1 до самого правого столбца и самой нижней определённой строки. Заголовков нет. Неопределённые ячейки этого прямоугольника записываются как пустые поля, если на них не было ссылок. Логические значения записываются как `true`/`false`. Числовые ответы имеют обычную десятичную или экспоненциальную запись. Дробное значение, точно равное целому с модулем меньше 10^16, записывается без `.0`. Пустую строку и неопределённую ячейку нельзя различить по CSV.

Весь расчёт выполняется перед записью. При ошибке расчёта прежний CSV остаётся. Запись идёт во временный файл рядом с результатом, затем заменяет целевой файл. Нельзя экспортировать поверх самой Python-программы или исходного `.tbl`; проверяется также совпадение через жёсткие ссылки. При переносе результата защита исходника относится к исходному абсолютному пути, записанному при трансляции.

Комментарии начинаются `#` или `//` до конца строки; `/* ... */` охватывает несколько строк без вложения. Символы комментариев внутри строк являются обычным текстом.

## Ошибки

```text
bad.tbl:2:10: семантическая ошибка [E_UNDEFINED]: Формула A1 обращается к неопределённой ячейке Z9.
  A1 = 2 + Z9;
           ^
```

Строка и позиция нумеруются с 1. Транслятор сообщает первую найденную ошибку. В сообщении выполнения указывается позиция исходной операции и вычисляемая ячейка, без стека Python. Возможны ошибки деления на ноль, переполнения или сохранения CSV. Ошибка при выполнении формулы, скопированной `fill`, указывает позицию исходного шаблона и имя конкретной ячейки.

| Код выхода транслятора | Значение |
|---|---|
| 0 | Успех, справка или версия |
| 1 | Ошибка исходного языка или UTF-8 |
| 2 | Неверные параметры командной строки |
| 3 | Файловая ошибка или нехватка ресурсов; сюда относится файл больше 16 МиБ |

Созданная Python-программа возвращает 0 при успехе и 1 при вычислительной или файловой ошибке. Сообщение успеха поступает в stdout, ошибка — в stderr. Потоки используют UTF-8.

## Ограничения

Исходник — не более 16 МиБ; значимых токенов — 100000; определённых ячеек и размера одного диапазона — 20000; граф — не более 200000 рёбер и не более 200000 обращений после раскрытия диапазонов, включая повторения. Глубина выражения и вложенность скобок/вызовов — 64. Литерал числа — не более 128 символов; координата не более 4 букв и 6 цифр до проверки границ. CSV — не более 1000000 полей; генерируемая программа — менее 32 МиБ с резервом на завершающий код. Строковый результат — не более 16 МиБ символов.

Возможности ограничены перечисленными конструкциями. Нет дат, листов, переменных вне ячеек, переопределений, циклов команд, пользовательских функций, ссылок на файлы таблиц и совместимости с синтаксисом Excel. Справка описывает именно язык TableScript.
